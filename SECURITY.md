# Security Policy

## Supported Versions

Currently, the `main` branch of this portfolio repository is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please DO NOT disclose it publicly. 

Instead, please send an email to the owner of this repository (contact information can be found on the portfolio website). All security vulnerabilities will be promptly addressed.

We take security seriously and appreciate your efforts to responsibly disclose your findings.
